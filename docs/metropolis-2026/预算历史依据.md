# 预算历史依据

本增量是 R09 AI 复盘的后端前置能力，尚未接入模型或手机端复盘入口。移动端保持 0.0.144 / Android 165；生产尚未部署。

## 留档规则

- 迁移 `202609160011_budget_history` 原子安装预算历史表及 PostgreSQL 触发器，同时记录启用时间。既有预算只在启用时间留基线，不把当前值回填到创建日期。
- 新建、修改、停用、删除预算自动留档，与业务写入处于同一事务。仅更新时间变化不产生新版本。金额在 JSON 中用十进制字符串保存。
- 删除预算后保留历史；删除用户时级联删除历史。历史没有指向预算的外键，因此可以解释已删除预算。
- 分类删除导致分类关联清空时，数据库同时停用对应预算，防止分类预算静默成为总预算。正常 API 写入只接受本人或系统提供的支出分类。

## 复盘内部读取

`BudgetHistoryService.evidence(userId, start, end)` 是内部服务，尚未暴露用户接口。查询区间为 UTC+8 业务边界转换后的时间戳 `[start, end)`，必须已结束且不超过 366 天。

查询开始早于留档启用时间时返回“无可核验的当期预算”。覆盖期间有任何预算规则变化时标记 `changed_in_period`，不向模型提供可直接用于超支判断的金额；只有完整覆盖且未变化的启用规则返回 `stable` 和依据版本 ID。后续更改、删除不影响更早的查询。结果按用户隔离并使用一致性快照。

调用方需要按预算周期选择比较范围：日复盘中月预算应比较月初至当日结束的累计支出，年预算应比较年初至当日结束；不能把月额度当成日额度。此处尚未计算支出。后续需使用统一账务口径，且只有匹配周期的稳定预算可以给出可核验的比较结论。
