# 移动端社群基础（待生产发布）

版本：0.0.137 / Android versionCode 158。入口：我的 → 设置 → 社群与隐私。

## 本批行为

- 社群必须阅读说明并主动勾选启用；默认不公开关系、不参榜、不允许好友文字用于 AI 复盘。
- 昵称或完整用户 ID 搜索，展示 ID 区分重名；自己的结果不提供关系操作。关注、粉丝、互关好友和拉黑名单分页读取。
- 个人关系页分开显示“我分享给对方”与“对方分享给我”；关注不等于账单授权。
- 授权选择收支范围与可选历史起始日期，展示本人真实账单的四字段示例及自定义分类隐私说明；必须再次勾选确认。非法日期不能提交，修改范围或日期后清除确认。
- 修改有效授权不重置原生效时间；撤销、退出、拉黑和解除拉黑提供确认。解除拉黑不恢复之前的关系或授权。
- 页面离开、切入后台时清除社群查询结果；返回重新读取。请求绑定发起界面的登录 token，过期界面响应不回填。
- 新增 `GET /social/grants/with/:id`，只返回当前用户与指定用户之间的两个方向授权，应用双方权限和拉黑校验。
