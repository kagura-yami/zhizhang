# 0.0.161 Android 日历列数修复

Android versionCode 182，安装包 40,313,759 字节（约 40.3 MB）。

用户报告 vivo S20 Pro 日收支日历只有六列、日期与星期错位。原布局使用屏幕宽度推算格宽并自动换行，存在容器宽度差异和小数 dp 精度导致换行的隐患。改为按实际容器宽度布局、每周明确七个等分槽位，月末空位补齐；星期表头同样等分。月视图和年视图复用固定四列、三列布局。

- 新增回归覆盖闰月、六周月份、日期完整性、星期列映射、尺寸变化与点击日期回调。
