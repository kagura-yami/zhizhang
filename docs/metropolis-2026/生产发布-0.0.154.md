## 页面调整

- 社群顶部只保留消息入口，主栏目为互评账单与排行榜，AI 复盘改为紧凑入口。
- 我的反馈、评账申请、我的举报集中到消息。
- 隐私设置放回“我的”设置列表，与启用社群分开。
- 个人主卡片上方展示头像及个人信息，下方为我的关注、关注我的、好友。关闭社群时点击关系入口进入启用说明，不自动开启。
- 查找用户只出现在好友内，评账授权及拉黑管理也在好友页。
- 采用细分隔线与分组列表，减少粗框和大按钮；空列表与仅一页列表隐藏分页。
