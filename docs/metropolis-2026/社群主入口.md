# 社群四分页与授权账单入口

0.0.144 / Android 165 本地实现并构建，尚未生产发布。

## 手机端流程

“我的”页面的应用菜单进入“社群”，默认打开 **互评账单**。顶部固定四个分页：互评账单、我的反馈、排行榜、关系管理；消息和隐私为辅助入口。没有新增总览页或普通聊天列表，也没有改动首页五项底部导航及现有 AI 页面。

- 未启用用户先阅读范围说明并主动勾选，成功启用后进入四分页；默认不参榜、不公开准确金额等设置不变。
- 互评账单先按账号展示当前有效授权、待评/已评价数量。选人后默认待评，可切换已评价/全部；账单按发生日期、时间倒序，按当前收入/支出/历史范围过滤。只有投票生成后才算已评价，不以“打开过页面”判断。
- 我的反馈按本人账单汇总票数，点击后进入每位评价者分别独立的对话。汇总列表不返回文字正文。已删除账单保留存档入口，由原线程权限继续保证主人只读、评价者断权。
- 排行榜复用 0.0.143 完成的全站/好友日月年榜及隐私设置。
- 关系管理包括查找、关注、粉丝、好友、已拉黑，并新增评账授权和申请入口。授权列表分“我分享的/分享给我的”，可调整分享范围、重新授权、撤销或退出；当前被拉黑或停用的对方不在列表中展示。

子分页按选中项挂载，沿用失焦/后台清除私密响应、过期请求隔离及渲染会话绑定，不新增持久化社群缓存。

## 接口增量

| 接口 | 用途与权限 |
|---|---|
| `GET /social/reviewable-owners?page=1&pageSize=20` | 当前用户收到的有效授权账号，附当前可见范围内的待评/已评价计数和总账号数；停用、未启用、双向拉黑、撤销及退出均排除 |
| `GET /social/owners/:id/bills?state=pending\|reviewed\|all&page=1&pageSize=20` | 新增状态筛选及 total；手机默认 pending，服务端省略 state 仍为 all，兼容旧调用；详情继续执行双方锁与即时授权检查 |
| `GET /reviews/mine/bills?page=1&pageSize=20` | 按本人 originalBillId 分组分页，返回四字段快照、删除状态、票数；不返回任何评价正文，不串联不同评价者会话 |
| `GET /social/grants/given\|received` | 复用授权列表并补当前对方可见性过滤；修改/结束仍使用既有授权接口 |

账号及反馈汇总在 RepeatableRead 快照中读取；分页在数据库执行，不在客户端截取前若干账号或线程。没有新增数据库表或迁移，但发布 APK 前仍需先部署兼容 API。
