# 0.0.163 设备绑定长期登录

Android versionCode 184，APK 40,296,135 字节（约 40.3 MB）。升级后需要重新登录一次，才能使用设备绑定会话。

## 行为与实现

- 新 Android 登录生成 Android Keystore EC P-256 密钥，私钥不导出；服务器保存公钥和可撤销设备会话。
- 访问 JWT 有效期 30 分钟，原生网络层在到期前两分钟串行续期。使用服务器签发的两分钟挑战和设备签名，不保存可复制的长期 bearer refresh token。设备会话连续 180 天不使用失效，续期滑动延长。
- 每个认证请求签名 HTTP 方法、路径及查询、Token 哈希、时间戳和 nonce；服务端要求签名、两分钟时钟窗口，并用数据库唯一约束防重放。这是项目自有签名协议，不声称符合 OAuth DPoP 全部格式要求。
- React Native 请求、原生自动记账、通知原文上传、桌面组件及语音请求共享续期能力，仅向同源 API 添加签名。
- 401 清除安全存储、原生 Token 和查询缓存，退出账本并提示；并发失效只提示一次，旧账号请求不能退出新账号。后台原生失效事件与前台会话检查均已接入。断网/5xx 不清除登录。
- 在线退出撤销当前设备会话；离线退出清理本地。密码修改事务撤销所有新设备会话和生物识别凭据。新生物识别绑定同时保存公钥，复制凭据不能换公钥登录。
- Android 已禁止应用备份。换手机/重装需要重新登录；不保证抵御 root 或已被控制的应用进程，不阻止主动分享密码。
- 旧版 bearer JWT/旧生物识别凭据继续兼容，不具备新绑定保护；用户需重新登录/重新绑定。iOS 尚未启用该 Android 原生机制。
