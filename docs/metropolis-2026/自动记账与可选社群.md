# 自动记账与可选社群

2026-09-17 用户确认的产品边界，覆盖此前要求人工核对账单的设计。

## 产品行为

- 知账首先是自动记账平台。已有和新建账单保存后直接参与首页、统计、预算计算，不要求逐笔确认。
- 社群是可选扩展。设置中的“社群开关与隐私”负责启停；启用后底部增加“社群”，关闭后恢复五个普通入口。
- 启用时说明日常账单自动参榜，默认全局榜、隐藏具体结余金额。用户仍可在社群调整参榜范围与金额隐私。
- 好友评账、反馈对话、排行榜、关系、社群消息和消费复盘集中在社群。账单详情和首页不再放核对、评账入口。
- 关闭社群退出排行榜，撤销双向评账授权、待处理申请和关注关系；账单及普通记账功能保留。重新启用不会恢复旧授权。
- AI 继续使用当前用户自行配置的 API；社群复盘不提供平台兜底密钥。

## 结构、依赖与数据流

```text
账单（Prisma Bill）
  → LedgerAccumulator（Decimal 自动汇总）
    → 首页 / 收支统计 / 累计结余 / 预算
    → 排行榜投影（仅启用且参榜的用户）
    → 社群 AI 复盘证据

设置 → SocialSettings → /social/enable POST 或 DELETE
  → SocialService 事务与用户锁 → 社群偏好 / 排名 / 授权
  → communityChanged → AppNavigator 状态刷新
    → BottomTabBar 条件显示 → SocialCommunity
```

React Native 沿用原有主题、导航和共享请求状态组件；NestJS 服务沿用 Prisma 事务、用户行锁及已有授权检查。没有增加数据库字段或迁移。普通汇总不依赖社群是否启用。

账务规则版本改为 `2026-09-17.auto`：无分类记录的账单按已有收支类型计入；同一用户关联支出的收入识别为退款。此前明确设置的转账、调账、忽略等覆盖仍保留；非法金额或不支持币种不混入人民币统计。旧分类接口仅为兼容保留，移动端不再注册核对页面。

## 验证与边界

- 后端 62 项单元测试通过；包含 501 条无人工确认记录自动入账。
- 12 组隔离数据库升级集成测试通过，覆盖汇总、历史结余、预算、社群停用/重启、榜单自动计入、授权和通知等；四种模型适配器 36 次合成 HTTP 请求通过。
- 移动端 12 组、32 项测试通过，包含五/六入口切换和自动更新失败重试；TypeScript 检查通过。
- RN Web 合成数据预览检查首页金额、预算和社群入口布局。浏览器预览不等于 Android 真机验证。
- 本次也修复手动更新静默下载、进度不可见、缓存 APK 丢失及安装权限失败的反馈。用户之前报告的更新失败已自行恢复，不能断言实际原因。

生产发布结果单独记入版本发布记录，不以本地测试代替上线验证。
