# 手机端累计结余

版本 0.0.149 / Android 170，配套 `/ledger/cash-history`，尚未发布生产。

## 页面行为

统计页原“资产”入口更名为“累计结余”。项目尚无完整期初资产、账户余额和负债记录，旧的“收入减支出 = 净资产”不成立；本次保留账本积累和趋势功能，明确其含义。

主卡片展示服务端返回的全部历史已确认累计结余，普通收入、退款、消费独立列出，显示统计截止日期与未确认状态。截止本月末，包含本月已录入的未来日期，之后月份不计入。不在前端加减原始账单或用近期月份反推期初金额。

近十二个月折线使用服务端累计值，保留空月份；历史未确认会影响后续累计点的完整性。可展开十二个月明细，逐月查看累计值、当月结余、退款、累计/本月待核对数量，并核对该月。

累计未确认提示提供四位年份输入与“选择最早年份”。范围限制在历史起止年份内，调用原账务核对页面，每次最多一个自然年；当前年截止本月末。可处理早于近十二个月的记录，避免把数年范围直接传入有 366 天上限的接口。确认后返回重新加载累计结果。

近十二月分类构成分别展示消费、普通收入和退款，保留所有分类、金额及比例。退款按自身分类展示，不抵减原消费。图表宽度随容器适配，不再使用固定宽度。

## 数据与状态

请求固定发起账号的认证令牌，不使用共享持久化资产缓存；离页、后台清除读取结果，账号切换重建页面。失败显示错误和重试，不伪造零资产。空账本成功响应才显示零结余。核对页原“不会更新首页”提示同步修正为首页、收支、预算和累计结余刷新时采用新口径，封榜记录仍不重算。
