# 移动端预算管理：统一账务口径

版本：0.0.147 / Android 168。此页说明本地完成和验证范围，不表示已发布生产。

## 用户行为

预算管理改用 `/budgets/ledger-progress`。按服务端返回的 UTC+8 当前月或年、当前预算设置比较已确认人民币消费；退款单列，内部转账、调账和忽略项不计入。不会把当前设置当作历史预算。

- 显示已确认消费、预算、退款、实际周期和使用比例。比例超过 100% 保留数值，进度条最多填满。
- 有待核对账单时显示数量和“不完整”提示，不给出最终剩余额度。已知消费已超过预算时标为“已确认至少超支”。顶部“待确认”与“确认已超”可以重叠。
- 零预算可创建和编辑；不计算百分比，已确认消费大于零即超支。
- 每项提供周期账单核对入口；核对页展示整个周期的账单，分类预算并不限制核对页的分类范围。返回后重新读取预算结果。
- 加载中及失败时不显示空预算结论，失败提供重新加载。真正没有预算才显示创建入口。
- 编辑从指定分类切到全部分类发送 `categoryId: null`；金额最多四位小数，预警百分比为 1–100 的整数。失败保留表单并提示，不把更新零条视作成功。

## 会话和兼容

预算和分类读取不进入持久化查询缓存，离开页面或进入后台清空读取结果。请求固定发起账号的认证头，过期响应不应用；切换认证令牌重建页面和表单。写入沿用同一账号，禁止重入，成功后刷新并使原首页预算缓存失效。

旧 `/budgets/progress` 仍为其他页面兼容保留。首页预算卡片、资产及旧分析页尚未完成新口径整合，本次不将其宣称为已完成。上线需先部署包含新接口的后端，再发布 APK 与更新 `/app-version`。
