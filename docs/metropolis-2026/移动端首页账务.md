# 首页统一账务口径

本地版本 0.0.148 / Android 169，未发布生产。

## 首页汇总和近期交易

首页完整自然月汇总来自 `/ledger/analytics`，当日取同一次返回的日汇总，按 UTC+8 确定年月日。结余使用服务端 `cashSurplus`，即普通收入 + 退款 − 消费。普通收入不含退款，内部转账、调账、忽略项不计入，待核对数量单列。月汇总包含已录入的未来日期账单，与主统计页及当前月预算一致。

原主指标和次级指标偏好保留，负结余保留负号；提供退款、排除数量、不完整提示和周期账单核对入口。加载失败显示重试，不把失败当作零收入或无账单。

近期列表保留本月最多 100 条原始记录，明确标注“最近 N / 总条数”，提供查看全部。按账单 `date` 分组，不再因通知时间或创建时间被分到别的日期。分组财务小计来自完整日汇总，不累加这 100 条原始记录；因此列表可能不含某笔收入，日汇总仍准确包含整日收入和退款。

汇总和原始列表是两个并行接口，不共享同一数据库快照；并发修改时可能短暂不同，刷新重新获取。财务汇总内部仍是后端同一事务快照。首页数值不以原始列表修补或回退。

## 预算卡片和图表

预算卡片使用 `/budgets/ledger-progress`，与预算管理页一致。展示消费、额度、退款、周期、待核对和超支；零预算显示无百分比，不伪造 0%。保留卡片堆叠，并提供“下一张”按钮；高度跟随内容，底层卡片不抢点击或读屏焦点，管理入口进入实际 `Budgets` 路由。

财务目标仍是用户手动维护的目标，不作为已确认账务事实。预算和目标独立显示请求错误，不因某项失败展示“未设置”结论。请求固定当前认证令牌，离页/后台清除结果，账号切换重建页面。

每日趋势和本月分类图使用同一月度汇总；分类全部纳入，不再截取前八项导致比例失真。年度图按需加载五年完整汇总，收入不含退款，各年退款与待核对数量独立展示，失败提供重试。图表宽度跟随卡片容器，适配窄屏。
