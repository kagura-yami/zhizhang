# 0.0.162 分类图标配色修复

Android versionCode 183，APK 40,314,883 字节（约 40.3 MB）。

账单列表原先用收入/支出类型决定图标底色，导致全部收入分类都是绿色，且与首页的分类色表不一致。现统一首页、全部账单、日收支账单、账单详情及通用交易组件的配色：工资淡金、交通淡蓝、购物淡粉、娱乐淡紫；未分类/其他为中性灰，其他分类支持自定义十六进制颜色及稳定名称回退。半透明浅底兼容明暗主题，金额的收支颜色保留。

- TypeScript、39 项 Jest、49 项 Android 单元测试和签名 Release 构建通过。
