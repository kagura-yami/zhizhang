# 0.0.158 社群入口按账户保持

Android versionCode 179，安装包 40,312,139 字节（约 40.3 MB）。

问题来自 MainNavigator 使用 useSocialResource：页面失焦、切到后台和每次刷新时都会清空 value，底部导航因而将社群当作关闭。现在使用独立的 useCommunityState，按用户 ID 保存布尔开关到本地；先恢复该账户开关，再呈现导航，后台同步服务器状态。刷新或网络失败不会清空入口；明确关闭后立即更新；账户切换隔离，旧请求不能覆盖新设置。设置操作保存成功后同步账户开关，即使设置页已失焦也会完成同步。

仅缓存社群是否启用，不缓存账单、好友内容或访问权限。社群数据请求继续由后端鉴权。已有用户首次更新后需要成功同步一次状态，后续启动可直接恢复。
