# 分类与季度分析

版本 0.0.150 / Android 171。统计页增加“分类与季度分析”入口，进入现有 `Statistics` 路由。

## 口径与行为

原统计分析页面改用 `/ledger/analytics`，保留本月、上月、本季度和本年度范围，统一 UTC+8 完整自然周期。普通收入、消费、退款、结余分别显示；分类构成保留全部分类，并支持消费/收入/退款切换。退款不当作普通收入，不抵减原消费分类。

消费与普通收入之比只在完整且收入大于零时计算。收入为零明确显示比例无定义，不再以 1 作替代分母；待核对数据不生成看似精确的收支比例。超过 100% 的实际比例允许显示。

月度范围展示每日消费趋势，季度/年度展示各月消费趋势，逐月退款和未确认数量单列。没有已确认消费时显示明确空状态。提供原账务核对入口。失败显示重试，不显示旧周期或伪零汇总；请求绑定发起账号，离页/后台清空读取结果。

## 验证与范围

- TypeScript 和八组定向测试共 20 项通过，包括 UTC+8 跨年、上月回退、闰年二月、季度边界、零收入/未确认比例。
- RN Web 实际页面连接本机 NestJS + PostgreSQL 合成数据库，验证统计主入口、四种周期、普通收入 1000 / 消费 118 / 退款 50 / 结余 932、105 条待确认、空上月及另一账号隔离。
- 验证切换周期时接口 503、旧结果隐藏、重试恢复，查看 390px 浅色及 320px 深色截图。
- Release APK 构建并核验版本，尚无原生设备验收；生产 SSH 不可用，未发布 APK 或更新 `/app-version`。

`reports/CategoryAnalysisScreen.tsx`、`reports/TrendAnalysisScreen.tsx` 未注册导航；`hooks/useStatistics.ts` 当前没有实际调用者。这些旧文件仍保留，未冒称已迁移。实际注册的 `Statistics` 路由及主统计、首页、预算、累计结余页面已完成本地新口径接入，生产和完整功能验收仍以交付矩阵为准。
