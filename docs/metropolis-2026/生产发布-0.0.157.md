# 0.0.157 排行榜与好友申请

发布时间：2026-09-17。Android versionCode 178，包名 com.zhizhang。

排行榜将总榜/好友榜、日月年和周期选择压缩展示；我的名次改为摘要，用户行始终显示头像（缺失或失败显示昵称首字），点击进入资料页。资料页优先展示个人信息与好友操作，评账授权保留在下方。

发送好友申请自动关注对方；对方在社群消息或申请者资料页同意后回关，互关即好友。重复发送和并发接受不重复建边/通知；取消关注后旧申请失效，拉黑或关闭社群后不可接受。已处理申请不能通过重放恢复解除的好友关系。好友不会自动获得账单查看或评账权限。

## 实现与验证

- API：POST /social/users/:id/friend-request；POST /social/friend-requests/:id/accept。
- 使用现有 SocialFollow generation 与 SocialInboxEvent，无数据库结构迁移。
- 独立本地 PostgreSQL 的 test/friends.integration.cjs 验证 HTTP 身份校验、并发去重、自动关注、接受回关、消息投影、未授权账单、旧申请、拉黑及关闭社群。
- 后端 68 项单元测试、移动端 34 项 Jest、49 项 Android 单元测试通过；TypeScript 和 Release 构建通过。
- RN Web 合成数据验证排行榜→资料→发送申请、消息接受申请；检查 320/390 宽屏、深色模式及头像回退。未连接生产账号进行社交操作，未完成新 APK 真机端到端验收。
- 应用内通知可用；后台系统推送仍依赖未配置的厂商通道，不能视为已验收。
