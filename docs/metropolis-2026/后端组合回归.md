# 后端组合回归

入口位于 `backend/test/run-social-regression.cjs`。在后端目录运行：

```powershell
npm test -- --runInBand
npm run test:social:integration
```

需要已安装后端依赖、可用 Docker 和包含 `cd1acb8` 的 Git 历史。执行器重新生成 Prisma Client、编译 Nest，然后启动随机名称 `zhizhang-regression-<UUID>` 的 PostgreSQL 16 临时容器，仅绑定本机 `15449`、`15451`；端口占用时失败，不停止现有服务。运行器自行设置合成数据库连接，不接受生产数据库作为目标。

每个数据库用 `cd1acb8` 的 schema 建立旧版基线，再顺序执行当前 011–015 迁移，包含预算留档和复盘隐私失效触发器，而不以 `db push` 代替迁移。每组测试前用 Prisma diff 检查升级结果与当前 schema 一致。未来新增 schema 或迁移时须维护这条升级路径，结构差异会导致失败。它不验证 001–010 从更早生产库的升级；那些迁移仍需单独验证。

覆盖十一组真实数据库/HTTP 链路：统一账务、预算进度、关系授权、评账申请、私密文字、文字写入限流、举报审核、消息中心、新账单通知队列、排行榜、持久化复盘。最后运行四种模型适配器的本机 HTTP 模拟测试。预算基线专项和 AI 取数专项脚本拥有不同建库前提，仍需单独运行；本命令不冒充全部生产验收。

测试包含刻意触发的通知写入异常和上游模型失败，日志中会出现相应 ERROR；是否通过以断言及进程退出码为准。没有连接外部模型，也不消耗模型额度。用到的用户名、账单和密钥均为合成数据。

正常完成或捕获到失败后，执行器停止自己创建的容器，由 Docker 自动删除容器及其匿名数据卷，并清理本次系统临时目录。不会清理项目运行数据或其他容器。强制结束进程或 Docker 不可用可能中断清理，需检查带 `zhizhang.synthetic-regression=true` 标签的本次容器并按完整名称停止。

这组检查不能替代真机跨账号、实际供应商模型质量、系统推送、生产迁移/发布、支付闭环和路演演示验收。当前移动端为 0.0.146 / Android 167，生产版本未更新。
