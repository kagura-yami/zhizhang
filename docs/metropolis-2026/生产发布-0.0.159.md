# 0.0.159 统一轻量卡片风格

Android versionCode 180，安装包 40,312,627 字节（约 40.3 MB）。以“我的”页面作为视觉基准：暖色背景、白色圆角表面、细分隔线、彩色图标，深色模式使用对应暗色表面。

## 变更

- 统一基础圆角、细边框和轻阴影，覆盖通用控件、记账、统计、社群、AI、设置等页面。颜色选中态、错误态仍保留。
- 首页收支由蓝色大色块改为白色摘要，主指标、辅助收支和金额层级重新排布，保留个性化指标配置及收支跳转。长金额可缩放显示。
- 预算管理改成区块标题旁的入口，预算与目标仍通过原卡堆拖动切换；根据卡片实际布局统一最低高度，避免较长卡片内容从底层露出。
- 保留 PanResponder 手势判断、拖动飞出方向、280ms 飞出、spring 回弹以及交易列表交错入场动画。按压组件保留原位移反馈，仅降低阴影层不透明度。
- 底栏细化边框和图标，记账按钮保留黄色强调与点击入口。

## 验证

- TypeScript 检查、13 个 Jest 套件共 35 项测试通过。
- Release 构建、49 项 Android 原生单元测试通过，签名与旧版一致。
- RN Web 使用实际组件及合成接口数据：检查首页、个人页、统计、社群、AI；首页检查 320/390 宽度及深色模式。
- 浏览器 CDP 触摸事件验证卡片拖动切换；缓慢短距离拖动验证回弹与索引保留；按钮轮换验证目标卡显示，修正等高后不再露出底卡文字。
- 浏览器没有原生动画模块，使用 RN Web 的 JS 动画回退；不能替代真机流畅度和 Android 手势仲裁验收。尚未安装新 APK 到真机。
