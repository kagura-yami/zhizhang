# 0.0.156 更新下载优化

2026-09-17。代码提交 `2af0bb0`，Android versionCode 177；后端沿用 `review-0.0.155`，无需重启或迁移。

## 实际收益

APK 从 72,416,879 字节降到 40,305,415 字节，减少 32,111,464 字节，约 44.3%。保持 armeabi-v7a、arm64-v8a、x86、x86_64 四种架构及全部 60 个原生库。原生库由约 49.4 MB 压缩到约 17.8 MB；未删除功能或架构，未开启新的混淆。使用 Android 官方支持的 [useLegacyPackaging](https://developer.android.com/reference/tools/gradle-api/8.3/com/android/build/api/variant/JniLibsApkPackaging) 进行原生库压缩，安装时解压，减少下载传输量；并不等于提升服务器出口带宽。

本次包体缩减对旧版下载立即有效；以下下载器优化在安装 0.0.156 后生效。

## 下载行为

前台首页、“关于”页面和 WorkManager 共用 `ApkDownloadCoordinator` 和缓存。串行下载并复用已校验文件，避免抢占带宽重复下载。使用固定 `.part` 与 `.resume` 保存断点及 URL/ETag（无强 ETag 时用 Last-Modified），以 Range + If-Range 请求余下内容。响应 200 时截断重下，206 检查 Content-Range 与校验标识；不匹配或 416 时清除无效断点后重试。断网时保留有效片段，下次继续；后台失败交给 WorkManager 重试。

长度符合预期且 APK 包名、版本通过系统校验后才原子替换最终路径；失败片段不能进入安装器。前台继续使用已有下载进度条，关闭页面不会中止统一下载。兼容旧原生 APK 的 JS 热更新仍保留 RNFS 路径。
