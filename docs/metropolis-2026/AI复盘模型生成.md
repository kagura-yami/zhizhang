# AI 复盘模型生成

此批实现内部 `RetrospectiveGeneratorService` 与输出校验器；尚未增加公开生成接口、持久化作业、历史报告、删除接口或手机端入口。完整 R09 尚未交付，生产未部署。

## 只读生成

复用用户本人的 OpenAI、Claude、DeepSeek、Qwen 配置及适配器；配置查询绑定认证用户，不能指定别人的模型配置。专用生成器不依赖普通 ChatService 或 ToolExecutorService，调用时传空工具列表；即使模型返回工具调用也直接拒绝，不执行。

模型只收到匿名化的完整证据载荷，不收到来源数据库 ID 映射、用户 UUID、API 密钥或邮箱/发票数据。没有对输入账单或评价做静默截断。当前采用一次完整请求；超过所选模型上下文窗口时必须失败并提示重试，长上下文分块编排及真实模型质量评测仍待后续验证，不能把本地模拟模型通过等同于生产生成效果。

请求支持 AbortSignal，最长 120 秒中止底层 fetch。复盘请求启用上游错误脱敏，不把可能回显原文的供应商错误响应写入日志或返回客户端。普通聊天调用的既有行为保持兼容。

## 输出合同

- 财务汇总、预算比较和数据缺口始终采用服务器结果，模型不能覆盖它们。
- 好友观点最多五项，引用必须属于本次有效 reviewer 文字，节选必须逐字包含于原文。本人回复和投票不能冒充好友文字理由。
- AI 解释最多五项、行动最多三项。每段最多五百字、最多五个引用；有证据时要求提供有效引用。拒绝未知引用、额外字段、非 JSON、过长结果、输出截断和工具调用。
- 解释和行动只承担定性建议；数字事实由服务端区域呈现。检查会拒绝数字字符及常见中文数字数量表达、链接和 HTML。它不是完整的自然语言事实证明器；引用存在不等于模型的所有语义推断都正确，真实模型评测和明确区分事实/建议仍是交付条件。
- 生成前采集一次证据，生成后再采集并比较摘要；在途账单、评价、授权等变化时拒绝旧结果并要求重试。用户在调用已发出后撤销授权，不能撤回已经发给模型的请求内容；后续结果会被拒绝。

内部返回包含报告版本、输入摘要、来源版本、取数与生成时间、模型提供商/模型名、提示词版本和账务规则版本。报告持久化和每次读取时的违规/授权复查仍需实现，不能把生成后的一次校验代替报告生命周期管理。

## 验证

后端 57 项单元测试通过，包括输出归属、精确原文、禁止模型数字事实、行动上限、用户模型配置归属、在途来源变化、取消、超时及错误脱敏；编译通过。

`backend/test/retrospective-generator.integration.cjs` 启动本机临时 HTTP 模型模拟端，实际运行四个现有适配器，验证 501 笔完整输入、无工具、有效结果、工具/截断拒绝、上游错误脱敏和在途取消，共 20 次请求。没有调用外部模型、使用真实账单或消耗模型额度；脚本结束关闭本机监听及连接。

本批只修改后端，移动端保持 0.0.144 / Android 165。生产发布仍待服务器连接恢复。
