# AI 复盘模型生成

当前已实现 `RetrospectiveGeneratorService`、输出校验器与分批生成。公开接口、持久化作业和手机端入口分别见[作业与历史](AI复盘作业与历史.md)、[移动端复盘](移动端AI复盘.md)。完整 R09 尚未交付，生产未部署。

## 只读生成

复用用户本人的 OpenAI、Claude、DeepSeek、Qwen 配置及适配器；配置查询绑定认证用户，不能指定别人的模型配置。专用生成器不依赖普通 ChatService 或 ToolExecutorService，调用时传空工具列表；即使模型返回工具调用也直接拒绝，不执行。

模型只收到匿名化证据，不收到来源数据库 ID 映射、用户 UUID 或邮箱/发票数据；API 密钥只用于供应商认证。小载荷一次生成，大载荷按 UTF-8 JSON 16,000 字节分批，所有账单、分类、有效文字、投票和预算比较均进入叶子批次。每批保留全周期服务端总额，并明确明细不完整；不静默截断原文。此上限不含系统提示词，也不保证任意用户配置模型的 token 窗口都足够。

每个中间结果最多一项好友原文、一项分析和一项行动，每段最多八十字、两个引用；先校验，再逐层合并。合并只携带已校验的建议、引用和原文节选，模型建议不提升为财务事实。最后用完整原始证据再次校验，并返回完整服务端事实和预算。单条超长、无法合并、非收敛、非法引用或任一请求失败都会终止整次生成，不保存半份报告。完整发送不等于最终摘要逐笔展示或已经证明模型理解了每笔数据；真实模型质量评测仍待完成。

请求支持 AbortSignal，每次最长 120 秒、整次模型编排最长八分钟。多批次会产生多次供应商计费请求；部分失败也可能已产生费用，不自动重试。每次发送前检查作业归属和失效状态，撤权后不再发下一批。复盘请求启用上游错误脱敏，不把可能回显原文的供应商错误响应写入日志或返回客户端。普通聊天调用的既有行为保持兼容。

## 输出合同

- 财务汇总、预算比较和数据缺口始终采用服务器结果，模型不能覆盖它们。
- 好友观点最多五项，引用必须属于本次有效 reviewer 文字，节选必须逐字包含于原文。本人回复和投票不能冒充好友文字理由。
- AI 解释最多五项、行动最多三项。每段最多五百字、最多五个引用；有证据时要求提供有效引用。拒绝未知引用、额外字段、非 JSON、过长结果、输出截断和工具调用。
- 解释和行动只承担定性建议；数字事实由服务端区域呈现。检查会拒绝数字字符及常见中文数字数量表达、链接和 HTML。它不是完整的自然语言事实证明器；引用存在不等于模型的所有语义推断都正确，真实模型评测和明确区分事实/建议仍是交付条件。
- 生成前采集一次证据，生成后再采集并比较摘要；在途账单、评价、授权等变化时拒绝旧结果并要求重试。用户在调用已发出后撤销授权，不能撤回已经发给模型的请求内容；后续结果会被拒绝。

内部返回包含报告版本、输入摘要、来源版本、取数与生成时间、模型提供商/模型名、提示词版本和账务规则版本，以及分批策略、叶子数、调用数、合并层数和输入覆盖数量。报告持久化及读取时的违规/授权复查由作业服务负责。

## 验证

后端 62 项单元测试通过；新增覆盖 1,400 笔账单、多层合并、最后一笔引用、输入字节边界、非法中间结果和单条超长拒绝；编译通过。

`backend/test/retrospective-generator.integration.cjs` 启动本机临时 HTTP 模型模拟端，实际运行四个现有适配器，验证 501 笔完整分批输入、无工具、逐层合并、工具/截断拒绝、上游错误脱敏和在途取消，共 36 次请求。作业数据库测试另验证三十秒续租及多批次在首批撤权后停止发送。没有调用外部模型、使用真实账单或消耗模型额度；脚本结束关闭本机监听及连接。

本批只修改后端，移动端保持 0.0.145 / Android 166。生产发布仍待服务器连接恢复。
