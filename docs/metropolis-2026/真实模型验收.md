## 可重复入口

脚本：`backend/test/retrospective-live-model.cjs`。先编译后端，从 backend 工作目录执行；必须显式提供以下非密钥配置：

```powershell
$env:RUN_LIVE_MODEL='1'
$env:LIVE_MODEL_OWNER='<已授权账号>'
$env:LIVE_MODEL_CONFIG_ID='<该账号的模型配置 ID>'
node test/retrospective-live-model.cjs
```

数据库连接使用已有运行环境。脚本只查询指定账号与配置 ID 的交集，不回退到其他用户；模型密钥只在进程内读取和发送给该配置原有服务商。启用会产生实际模型调用费用，最多 20 次 HTTP 请求，不加入自动 CI。
