## Dependencies

- 后端：Node.js 20、NestJS 10、Prisma 6、PostgreSQL 16 Alpine、JWT、Swagger、SSE。
- 移动端：Node.js 20、React Native 0.81.4、TypeScript、React Navigation 7、React Query 5、React Native Paper、SVG 和音频库。
- 邮箱：Microsoft Graph `Mail.Read` OAuth2；其他邮箱通过 ImapFlow/XOAUTH2；附件用 mailparser 和 PDF 解析器处理。
- AI：OpenAI 兼容协议，密钥只由用户在应用内配置或由服务端安全配置提供。
- 部署：Docker Compose → 本机 `3006` → FRP → 阿里云 ECS HTTPS（`note.kagurayami.top`）。
- 内测群助手：Node.js + Express + TypeScript，监听本机 `3007`，通过企业微信自建应用回调与主动推送；配置只放 `Bot/.env`，目录整体不提交 GitHub。

## Architecture Patterns

- Monorepo：根目录只编排两个子项目，不共享运行时数据库代码。
- 后端采用 NestJS 领域模块：Controller 定义 HTTP/SSE 契约，Service 负责业务，Prisma 负责持久化。
- 移动端采用页面、组件、Hook、Service 分层；主题和首页展示偏好通过 Hook + AsyncStorage 管理。
- 自动记账链路为“通知监听 → 平台/关键词解析 → 去重 → 分类 → API 写入 → 本地通知反馈”。
- 发票链路为“OAuth/IMAP 授权 → 邮件筛选 → PDF/图片附件提取 → 文本解析 → 哈希去重 → 发票中心”。

## Codebase Conventions

- TypeScript/TSX 使用 PascalCase 组件文件、camelCase 变量和 2 空格缩进。
- 后端按 `backend/src/<domain>/` 组织 Controller、Service、DTO 和测试。
- 秘密只放在被忽略的 `backend/.env`、`mobile/.env.production`、`mobile/android/keystore.properties`。
- 用户可见品牌统一使用“知帐”；Android 包名、原生包声明和 JS 注册名统一使用 `zhizhang`。

## Component Relationships

- `App.tsx` 组合 Provider、导航和全局更新检查；`AppNavigator` 将认证流、主 Tab 和二级设置页隔离。
- 首页由账户卡、预算卡、统计图表和可排序展示项组成；`useHomeDisplayPreference` 持久化顺序/可见性。
- 发票中心列表进入详情页；详情页读取整理后的字段并调用附件预览/下载；批量选择只在选择模式显示复选框和下载操作。
- 后端版本服务返回最新版本与跨版本更新日志；客户端启动和关于页触发检查并弹窗提醒。
